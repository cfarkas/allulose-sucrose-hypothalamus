FROZEN DERIVED INPUTS FOR SUPPLEMENTARY FIGURE S6

These tables were copied or derived from the audited Figure 5 experiment:
  analyses/Fig5/results/transfer_reviewed_20260907_v1/

human_reference.csv: 203 pseudonymous cell/animal identities and human classes,
with reviewer personal details omitted.
morphometric_predictions.csv: the existing fixed morphometric proposal for
each of those cells.
dinov2_predictions.csv: nested animal-held-out predictions for the same cells.
validation_design.json: outer held-out animals and inner selection partitions.
method_metadata.json: method definitions, sample selection, source hashes and
expected metrics from the audited training run.
RAW_DATA_MANIFEST.csv: exact sizes and SHA-256 hashes for the five model inputs.

The README itself is descriptive and is not an analysis input. No new human
labels or simulated observations were created. Existing Figure 5 microscopy,
masks, labels and prediction tables were not modified. SOURCE_FREEZE_RECEIPT.json
in ../provenance records the original sources and label-table derivation.
