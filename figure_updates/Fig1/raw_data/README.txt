FIGURE 1 RAW DATA
=================

This directory contains independent physical copies of every raw data file
required by the canonical Figure 1 analysis: cage-level bottle consumption and
mouse-level body weights from Experiment 1.

The exact source paths and SHA-256 hashes are recorded in RAW_DATA_MANIFEST.csv.
The sources are the paths named in docs/Commands_2026.txt, and both hashes match
that document's 2026-08-14 provenance snapshot. Files were copied with metadata
preservation and reflinks disabled. Source and destination hashes match, and
source and destination inodes are distinct.

The canonical analysis script's default runtime paths remain under
analyses/Fig1/raw/. This raw_data directory is the figure-local preservation
copy; no source file was moved, linked, or overwritten.
