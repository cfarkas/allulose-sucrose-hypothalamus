## Experimental units and interpretation

Behavioral measurements shared by a cage use the cage as the independent unit.
NPY abundance uses 5/3/3 Water/Sucrose/Allulose animals; the marker-associated
spatial endpoint requires two double-positive nuclei and uses 3/3/3 animals.
NPY cage membership is undocumented. POMC spatial curves average animals
equally within biological cages. Cells and sections are subsamples.

The Figure 3–4 spatial tests use conditional random labeling and global
envelopes across 20–150 µm, with Holm adjustment across the two endpoints.
These distances describe proximity. Acquisition differences and marker
detection remain relevant; see the [interpretation notes](MICROSCOPY_AND_INTERPRETATION.md).

Figure S3 uses cohort-adjusted, coefficient-specific Freedman–Lane tests with
matched HC3 statistics and Benjamini–Hochberg correction. Its HistoPLUS labels
are exploratory nuclear phenotypes. Figure 5 morphology predictions and the
Figure S6 internal benchmark do not independently establish functional glial
activation. Figure S8 estimates planning power under pilot-derived assumptions.

## Reproduce the figures

From the GitHub root:

```bash
python3 reproduce.py
```

The launcher downloads and verifies the Zenodo datasets, reconstructs `Paper/`,
installs the files listed in `figure-updates.json`, prepares the environments,
and runs the thirteen-figure workflow. Raw WATER_NPY4–5 images are not included
in Zenodo; reviewed coordinates support their portable numerical reproduction.
Each figure README identifies the inputs needed for its individual rebuild.

Recompute NPY/POMC statistics without microscopy:

```bash
python3 -m venv .figures-venv
.figures-venv/bin/python -m pip install -r requirements-figures.txt
.figures-venv/bin/python figures/scripts/shared/recheck_current_statistics.py
```

Render Figure S6 from its small prediction/reference tables:

```bash
.figures-venv/bin/python figures/FigS6/01_make_figure_s6_microglia_classifier.py --output-dir figure-renders/S6 --dpi 600
```

Normal runs reuse the saved 203 microglial choices. Optional independent review
is enabled with `python3 reproduce.py --do_microglial_choices`. The terminal
provides the local review URL; [Figure 5 instructions](figures/Fig5/README.txt)
describe mask review, labels, training and saved outputs.

## Verification

Checks cover source hashes, script syntax and mirrors, statistical recomputation,
input partitions, native microscopy displays, and English/Spanish panel pairing.
All 13 figure packages pass the output validator. The complete thirteen-figure
workflow has not been replayed end to end; individual reconstruction and
installation checks define the verified scope.

```bash
python3 validate_repository.py --root .
python3 validate_figure_updates.py
python3 -m unittest discover -s tests -v
```
